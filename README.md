## Featured project

### TradingSimulator (private repo, request access)

A full-stack paper-trading app. Users register, get virtual cash, buy and sell stocks at live prices, and track their holdings and portfolio performance over time.

- **Backend:** Spring Boot REST API, JWT authentication, Spring Data JPA, with market data from the Finnhub and Financial Modeling Prep APIs
- **Frontend:** vanilla HTML, CSS and JavaScript, no framework
- **Pages:** landing, login, market overview, assets and portfolio dashboard
